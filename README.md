# A Little World for Lovern ♡

A pink, rose-inspired romantic website made with plain HTML, CSS, and JavaScript. No database or build tools required. It is ready for GitHub Pages.

## Preview on your computer
1. Download and unzip the project.
2. Open `index.html` in your browser.
3. For the best experience, use a desktop browser and check the mobile layout too.

## Publish using GitHub Pages
1. Sign in to GitHub and create a **new repository**. A name such as `a-little-world-for-lovern` works.
2. Set the repository to **Public** if you want to use GitHub Pages on a free account, and create the repository.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder. Do not upload only the ZIP file.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. The Pages section will show your website URL, usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalize before publishing
- In `index.html`, replace the sample memory cards with your own photos and captions. For a photo, replace a placeholder `<div class="photo-placeholder ...">🌅</div>` with an image such as `<img class="memory-photo" src="images/your-photo.jpg" alt="A memory together">`.
- If you add images, create an `images` folder in the repository and upload the files there. Use lowercase file names without spaces.
- Edit the message and timeline to match your real story.
- Review the 100 reasons in `script.js` and change any reason that doesn't genuinely fit what you've noticed about Lovern.
- The yes/maybe buttons currently display a message on the page only. They do **not** send a notification or save her answer.
- If you want privacy, avoid posting private chats or photos without permission. A public GitHub Pages site can be viewed by anyone who has the link, and a public repository's source files can be viewed too.

## Notes
- The site uses Google Fonts when internet access is available; system fonts will be used if not.
- There is no background music by default, so the page does not start audio unexpectedly.
